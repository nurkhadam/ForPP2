# Practice 10: Pygame Development

This repository contains three projects developed using Python and the **Pygame** library as part of the Principles of Programming II course. Each project demonstrates advanced game mechanics, user interface design, and logic handling.

---

## 1. Racer Game
An arcade-style racing game where the player must navigate through traffic while collecting coins.

* **Key Features:**
    * Smooth movement control for the player's car.
    * **New:** Randomly appearing coins on the road.
    * **New:** Score counter for collected coins in the top right corner.
    * Collision detection system that ends the game upon hitting another vehicle.
* **Controls:** Arrow keys (Left/Right) to move.

---

## 2. Snake Game
The classic Snake game, enhanced with level progression and collision rules.

* **Key Features:**
    * **Border Collision:** Strict checks for wall collisions and playing area boundaries.
    * **Smart Food Spawning:** Food is generated at random positions, ensuring it never overlaps with the snake's body or walls.
    * **Levels & Difficulty:** Speed increases as the player collects more food (levels up every 3-4 items).
    * **On-screen UI:** Real-time display of current Score and Level.
* **Controls:** Arrow keys to navigate.

---

## 3. Paint Tool
A functional graphics editor for drawing shapes and freehand art.

* **Key Features:**
    * **Shapes:** Tools to draw perfect Rectangles and Circles.
    * **Eraser:** A dedicated tool to remove parts of the drawing.
    * **Color Selection:** Built-in color palette for switching between different drawing colors.
    * **Brush:** Basic freehand drawing functionality.
