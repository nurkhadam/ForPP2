# Practice 2 – Python Control Flow

This repository contains basic Python examples based on W3Schools topics.
Each topic is saved in a separate `.py` file.

## Topics Covered
- Boolean Values
- Booleans as Comparison Results
- Boolean Operators
- If Statement
- If Else
- If Elif Else
- Short Hand If Else
- Switch/If Elif/Else
- While Loops
- While Loop Break
- While Loop Continue
- For Loops
- For Loop Break
- For Loop Continue

## Structure
Each file includes 5 small code examples.
Examples inside files are separated by comments.

## Purpose
Practice basic Python syntax and concepts.
Complete exercises and "Try It Yourself" examples from W3Schools.

## How to Run
Use Python 3 to run any file:
python filename.py
